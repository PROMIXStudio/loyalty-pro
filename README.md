# Loyalty Pro

Application SaaS de gestion des abonnements et fidelite pour boutiques.

## Configuration
1. Renseigner les cles Firebase dans `assets/js/firebase-config.js`
2. Renseigner les cles CamPay dans `assets/js/campay.js`
3. Uploader sur Hostinger
4. Deployer les Cloud Functions : firebase deploy --only functions

## Paiement
Passerelle : CamPay (MTN Mobile Money / Orange Money)
Mode test : DEV | Mode production : PROD
